# PS-Wiki API and MCP Service Terms

**Last updated: 2026-09-14.**

These terms apply to the public, read-only PS-Wiki REST API and remote MCP
server. By using either service, you agree to use it lawfully and in a way
that does not impair the service for others.

## Service scope

The API and MCP server provide access to public PS-Wiki terminology data. The
remote MCP endpoint is `https://mcp.ps-wiki.ning.guru/mcp`. It currently exposes
read-only search, retrieval, relationship, and tag-browsing tools. The service
may change, rate-limit, or temporarily become unavailable without notice.

## Responsible use

Do not use the service to send confidential information, credentials, personal
data, or material that you are not authorized to disclose. Do not attempt to
bypass access controls, overload the service, or misrepresent PS-Wiki output as
an authoritative standard or professional advice.

When using definitions in other work, preserve the source citations and
attribution returned by the API or MCP tools. Wiki content is available under
[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/); those license
terms govern reuse of the content.

## No warranty

PS-Wiki is an open reference project. The service and its content are provided
on an “as is” basis. Check the cited primary source, applicable standard, or
professional guidance before relying on a definition for engineering,
operational, safety, legal, or commercial decisions.
